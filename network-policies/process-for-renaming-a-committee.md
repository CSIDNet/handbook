# Process for Renaming a Committee

1. ### **Initial Discussion within Committee**

* The committee discusses potential new names for the group.
* If disagreement arises and the group cannot reach a clear consensus, multiple options are documented.
* Each option should include a brief description of its scope along with pros and cons.<br>

2. ### **Escalation to Governance Committee**

* The documented options are shared with the Governance Committee for review.
* The Governance Committee is given **1-2 weeks** to provide comments and feedback directly on the document.<br>

3. ### **Governance Committee Review and Deliberation**

* Members review each other’s comments.
* The goal is to reach **consensus** (full agreement).
* If consensus cannot be reached, the group aims for **consent**—defined as at least one option that has **no opposition** (no one actively against it).<br>

4. ### **Decision-Making Criteria**

* If there is only one option with no opposition, that option moves forward.



5. ### **Implementation and Communication**

* The chosen name is formally adopted and communicated to all relevant stakeholders.
* Supporting documentation (including comments and rationale) is retained for transparency.
* The updated name is integrated into official materials, and the committee’s scope and responsibilities are clarified in the next meeting.
