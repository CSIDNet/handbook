# CSIDNet Handbook

[CSIDNet](https://csidnet.org/) is a global volunteer network working at the intersection of climate science, public health, and open source software. This handbook collects the shared agreements that keep a distributed community of practice running: participation norms, committee governance, working group terms, and how convenings are organised. The CSIDNet Governance Committee developed these policies and reviews them once a year. To suggest a change, email [operations@csidnet.org](mailto:operations@csidnet.org).
