# Master Planning Checklist

This checklist covers everything that needs to be planned, confirmed, and executed for a CSIDNet regional co-hosted event. It is owned jointly by the co-host team and the assigned EC representative. Items are organized by phase.

**Each team has a copy of this checklist saved in your Event's Google Drive Folder.** Check off each item in your check-list when confirmed (not when it is in progress).

Owner abbreviations: CH = co-host team | EC = Events Committee rep | BOTH = both parties

{% endhint %}

### Phase 1: Pre-planning (Before Meeting 1)

**Contracts and agreements**

* [ ] Co-host contract signed (EC)
* [ ] Scope of Work / Addendum confirmed (EC)
* [ ] IPF budget envelope communicated to co-host (EC)
* [ ] Co-host bank/payment details collected for reimbursements (EC)

**Internal co-host setup**

* [ ] Internal co-host team identified and roles assigned (CH)
* [ ] Primary contact confirmed for EC (CH)
* [ ] Logistics lead identified (CH)
* [ ] Program/content lead identified (CH)
* [ ] Finance/reimbursement lead identified (CH)

### Phase 2: Vision, Logistics, and Venue (Meeting 1, \~4 to 5 months out)

**Vision alignment**

* [ ] Event purpose and framing agreed between co-host and CSIDNet (BOTH)
* [ ] Target participant profile defined (geography, sector, career stage) (BOTH)
* [ ] Success metrics agreed (BOTH)

**Venue**

* [ ] Venue shortlist developed (CH)
* [ ] Venue capacity confirmed against expected attendance (CH)
* [ ] Accessibility assessed (physical access, transport, accommodation nearby) (CH)
* [ ] AV and internet reliability confirmed (CH)
* [ ] Catering arrangements confirmed or scoped (CH)
* [ ] Venue contract signed (CH)
* [ ] Venue deposit paid (CH)
* [ ] Backup venue or contingency plan noted (CH)

**Timeline**

* [ ] Shared working timeline drafted and agreed (BOTH)
* [ ] Key milestone dates set: program lock, invitations out, selection complete, participant confirmation, event (BOTH)
* [ ] Hard dependencies identified: visa lead times, deposit deadlines, institutional approvals (BOTH)

### Phase 3: Program and Speakers (Meeting 2, \~3 months out)

**Program**

* [ ] Draft program structure shared with EC (CH)
* [ ] Program narrative arc reviewed and agreed (BOTH)
* [ ] Session formats confirmed (plenaries, breakouts, informal time) (BOTH)
* [ ] Event length confirmed (half day, full day, multi-day) (BOTH)
* [ ] Run-of-show template started (CH)

**Speakers**

* [ ] Speaker list drafted with roles and session assignments (CH)
* [ ] Speaker diversity reviewed (geography, gender, sector, career stage) (BOTH)
* [ ] Speaker invitations sent (CH)
* [ ] Speaker confirmations received for all sessions (CH)
* [ ] Speaker briefing documents prepared (session length, format, expectations) (CH)
* [ ] Speaker travel and accommodation needs identified (CH)
* [ ] Visa letters prepared for any speakers who need them (CH + EC)

**Facilitation**

* [ ] Facilitator(s) identified for each session (CH)
* [ ] Facilitator briefing completed (CH)

**Outreach**

* [ ] Outreach strategy agreed (open call, invitation, or hybrid) (BOTH)
* [ ] CSIDNet membership list outreach coordinated with EC (BOTH)
* [ ] Application or expression of interest form live (CH)
* [ ] Application deadline set and communicated (CH)

### Phase 4: IPF and Participant Selection (Meeting 3, \~2 months out)

**IPF setup**

* [ ] IPF budget confirmed and broken down by eligible cost categories (EC)
* [ ] Eligible costs communicated clearly to co-host (EC)
* [ ] Reimbursement vs. advance payment policy clarified (EC)
* [ ] Reimbursement documentation requirements shared with co-host (EC)
* [ ] IPF disbursement timeline confirmed in writing (EC)

**Selection panel**

* [ ] Panel composition confirmed (co-host rep(s) and EC rep named) (BOTH)
* [ ] Selection window dates confirmed (EC)
* [ ] Panel meeting scheduled (synchronous session strongly recommended) (BOTH)
* [ ] Target cohort distributions shared with panel (EC)
* [ ] Conflict of interest declaration process confirmed (staff logs declarations) (EC)
* [ ] For Thailand only: fast-track contingency confirmed in writing (EC)

**Selection process**

* [ ] Finance Committee shortlist shared with panel at least 3 days before session (EC)
* [ ] Panel session held (consensus-based review against three criteria: relevance, contribution, cohort balance) (BOTH)
* [ ] Any conflicts of interest declared and logged before discussion begins (BOTH)
* [ ] Final cohort confirmed (BOTH)
* [ ] Waitlist established if applicable (BOTH)

**Post-selection**

* [ ] Acceptance notifications sent (CH)
* [ ] Decline notifications sent (CH)
* [ ] Waitlist notifications sent if applicable (CH)
* [ ] IPF grant amounts communicated to accepted participants (EC + CH)
* [ ] Reimbursement instructions sent to IPF recipients (EC)
* [ ] Visa support letters requested for any participants who need them (CH + EC)

### Phase 5: Pre-Event Logistics (4 to 6 weeks out)

**Participant logistics**

* [ ] All participant travel booked or confirmed (CH)
* [ ] Accommodation confirmed for all participants needing support (CH)
* [ ] Visa status confirmed for all international participants (CH)
* [ ] Participant transport to/from venue confirmed if relevant (CH)
* [ ] Dietary and accessibility needs collected and communicated to venue (CH)

**Communications**

* [ ] Participant confirmation email sent with event details (venue, schedule, what to bring, day-of contact) (CH)
* [ ] Speaker final briefing sent (CH)
* [ ] Facilitator final briefing sent (CH)

**On-the-day preparation**

* [ ] Run-of-show finalized (CH)
* [ ] Registration process confirmed (who runs it, what's needed) (CH)
* [ ] Name badges, printed materials, signage prepared (CH)
* [ ] AV tested and backup plan confirmed (CH)
* [ ] Meals and breaks confirmed with venue (CH)
* [ ] Accessibility setup confirmed (CH)
* [ ] On-the-day CSIDNet contact confirmed (BOTH)
* [ ] Emergency/contingency contacts list prepared (BOTH)

**Documentation**

* [ ] Note-taker assigned for the event (CH)
* [ ] Photography plan confirmed (CH)
* [ ] Post-event report format and deadline confirmed (BOTH)

### Phase 6: During the Event

* [ ] Registration managed (CH)
* [ ] Run-of-show followed and updated in real time (CH)
* [ ] Notes taken across sessions (CH)
* [ ] Photos taken (CH)
* [ ] Any issues escalated to EC contact promptly (CH)
* [ ] Reimbursement receipts collection process communicated to participants on the day (CH + EC)

### Phase 7: Post-Event

**Financial**

* [ ] IPF reimbursement receipts collected from participants (CH)
* [ ] Reimbursement claims submitted to CSIDNet with documentation (CH)
* [ ] All payments processed (EC)
* [ ] Final event budget reconciliation completed (BOTH)

**Documentation and reporting**

* [ ] Event notes compiled and cleaned (CH)
* [ ] Post-event report drafted (CH)
* [ ] Post-event report reviewed and submitted to CSIDNet by agreed deadline (CH)
* [ ] Photos shared with CSIDNet (CH)
* [ ] Any follow-up commitments made at the event logged (BOTH)

**Participant follow-up**

* [ ] Thank-you communication sent to all participants (CH)
* [ ] Thank-you communication sent to speakers and facilitators (CH)
* [ ] Any outstanding participant questions resolved (CH)
* [ ] Network-level
* [ ] Event debrief between co-host and EC rep completed (BOTH)
* [ ] Lessons learned documented for future co-host onboarding (BOTH)
