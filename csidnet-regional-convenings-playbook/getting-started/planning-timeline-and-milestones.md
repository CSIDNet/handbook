# Planning Timeline & Milestones

{% hint style="info" %}
Thailand co-hosts: your IPF and notification deadlines run approximately two weeks earlier throughout. Your EC rep will flag the specific dates for your event.
{% endhint %}

#### Before Planning Begins: Contracts & Setup

_Complete before Meeting 1_

| **Task**                                                       | **Owner**         |
| -------------------------------------------------------------- | ----------------- |
| Subaward contract signed                                       | Co-host + CSIDNet |
| IPF budget envelope communicated to co-host                    | CSIDNet           |
| Co-host bank/payment details collected                         | CSIDNet           |
| Internal co-host team identified and roles assigned            | Co-host           |
| Primary contact and logistics lead confirmed with CSIDNet      | Co-host           |
| Program/content lead and finance/reimbursement lead identified | Co-host           |

***

#### 4-5 Months Out: Vision, Logistics & Venue

_Focus of Meeting 1_

| **Task**                                                                                  | **Owner** |
| ----------------------------------------------------------------------------------------- | --------- |
| Event purpose and framing agreed between co-host and CSIDNet                              | Both      |
| Target participant profile defined (geography, sector, career stage)                      | Both      |
| Shared working timeline drafted and agreed                                                | Both      |
| Venue shortlist developed and assessed for accessibility                                  | Co-host   |
| Venue capacity confirmed against expected attendance                                      | Co-host   |
| AV, internet, and catering arrangements confirmed                                         | Co-host   |
| Venue contract signed and deposit paid                                                    | Co-host   |
| Key milestone dates set: program lock, invitations, selection, confirmation, event        | Both      |
| Hard dependencies identified: visa lead times, deposit deadlines, institutional approvals | Both      |

***

#### 3 Months Out: Program & Speakers

_Focus of Meeting 2_

| **Task**                                                             | **Owner** |
| -------------------------------------------------------------------- | --------- |
| Draft program structure shared with EC rep                           | Co-host   |
| Session formats confirmed (plenaries, breakouts, informal time)      | Both      |
| Event length confirmed (half day, full day, multi-day)               | Both      |
| Speaker list drafted with roles and session assignments              | Co-host   |
| Speaker diversity reviewed (geography, gender, sector, career stage) | Both      |
| Speaker invitations sent                                             | Co-host   |
| Facilitator(s) identified and briefed for each session               | Co-host   |
| Outreach strategy agreed (open call, invitation, or hybrid)          | Both      |
| CSIDNet membership list outreach coordinated with EC rep             | Both      |
| Participant registration or expression of interest form live         | Co-host   |
| Application deadline set and communicated                            | Co-host   |

***

#### 2 Months Out: IPF & Participant Selection

_Focus of Meeting 3_

| **Task**                                                                       | **Owner**         |
| ------------------------------------------------------------------------------ | ----------------- |
| IPF budget confirmed and eligible costs communicated to co-host                | CSIDNet           |
| Reimbursement vs. advance payment policy clarified                             | CSIDNet           |
| IPF disbursement timeline confirmed in writing                                 | CSIDNet           |
| Selection panel composition confirmed (co-host rep + EC rep named)             | Both              |
| Selection window dates confirmed and panel meeting scheduled                   | Both              |
| Target cohort distributions shared with panel                                  | CSIDNet           |
| Conflict of interest declaration process confirmed                             | CSIDNet           |
| Finance Committee shortlist shared with panel (at least 3 days before session) | CSIDNet           |
| Panel session held: final cohort selected                                      | Both              |
| Acceptance, decline, and waitlist notifications sent                           | Co-host           |
| IPF grant amounts and reimbursement instructions sent to recipients            | CSIDNet + Co-host |
| Visa support letters requested for participants who need them                  | Co-host + CSIDNet |
| Speaker confirmations received for all sessions                                | Co-host           |

***

#### 4-6 Weeks Out: Pre-Event Logistics

| **Task**                                                                             | **Owner** |
| ------------------------------------------------------------------------------------ | --------- |
| All participant travel booked or confirmed                                           | Co-host   |
| Accommodation confirmed for all participants needing support                         | Co-host   |
| Visa status confirmed for all international participants                             | Co-host   |
| Dietary and accessibility needs collected and communicated to venue                  | Co-host   |
| Participant confirmation email sent (venue, schedule, what to bring, day-of contact) | Co-host   |
| Speaker and facilitator final briefings sent                                         | Co-host   |
| Run-of-show finalized                                                                | Co-host   |
| Registration process confirmed (who runs it, what's needed)                          | Co-host   |
| Name badges, printed materials, signage prepared                                     | Co-host   |
| AV tested and backup plan confirmed                                                  | Co-host   |
| Note-taker and photography plan confirmed                                            | Co-host   |

***

#### 1-2 Weeks Out: Final Check

_Focus of Meeting 4_

| **Task**                                                           | **Owner** |
| ------------------------------------------------------------------ | --------- |
| Full program walkthrough with Events Committee                     | Both      |
| All open items from previous meetings resolved                     | Both      |
| Any at-risk participant travel or visa issues flagged and actioned | Co-host   |
| On-the-day CSIDNet contact confirmed                               | Both      |
| Emergency/contingency contacts list prepared                       | Both      |
| Post-event report format, deadline, and owner confirmed            | Both      |
| Final participant communication sent                               | Co-host   |
