# Accessibility & Inclusivity Checklist Template

A copy of this checklist will be saved in each Events' Google Drive folder for customization and use.

#### Venue & Physical Accessibility

* [ ] Is the venue wheelchair accessible (e.g., ramps, elevators, wide doorways, comfortable seating with back support)?
* [ ] Are accessible restrooms available and clearly marked?
* [ ] Is there reserved seating for participants with mobility needs?
* [ ] Is there clear signage inside and outside the venue?
* [ ] Is there a quiet prayer/low-stimulation space available?
* [ ] Are there sufficient charging ports for mobile devices and other electrical appliances?
* [ ] Have we confirmed emergency evacuation accessibility procedures?
* [ ] Is there on-site support staff briefed on accessibility?

#### Food & Dietary Needs

* [ ] Have dietary requirements/restrictions been collected and confirmed for all attendees?
* [ ] Has the venue/caterer confirmed accommodation of:
  * [ ] Food allergies (nut-free, gluten-free, etc.)
  * [ ] Halal meals
  * [ ] Vegetarian/vegan/kosher options
  * [ ] Other medical dietary needs/preferences
* [ ] Are all food items clearly labeled?

#### Language & Interpretation

* [ ] Will live interpretation be provided?
* [ ] If yes, have we specified the languages needed?
* [ ] Have interpreters been booked and confirmed? (If applicable)
* [ ] Have backup interpreters been arranged in case of last-minute issues? (e.g., in-house team)
* [ ] Are headsets/interpretation equipment arranged? (Optional)
* [ ] Have written materials been translated?
  * [ ] Agenda
  * [ ] Slides
  * [ ] Key documents
* [ ] Is there a plan for multiple simultaneous sessions needing interpretation? (If applicable)

#### Communication Accessibility

* [ ] Is there a technical support team/point of contact available?
* [ ] Are all presentation devices tested and functioning? (e.g., projectors, screens, etc.)
* [ ] Have we done a sound check?
* [ ] Are slides readable?
* [ ] Are videos captioned?
* [ ] Has a facilitator/moderator been assigned? (e.g., an external facilitator/in-house team)
* [ ] Has a designated point of contact been assigned to oversee audience questions?
* [ ] Are microphones available for audience questions?
* [ ] Are backup microphones available in case of technical issues?
* [ ] Have speakers been briefed on inclusive language?

#### Virtual / Hybrid Accessibility (if applicable)

* [ ] Have we done a test run?
* [ ] Is the internet connection stable and accessible to all participants?
* [ ] Are microphones and audio/video devices tested for presenters?
* [ ] Is the meeting link working and shared in advance?
* [ ] Are virtual breakout rooms or smaller group discussions tested for accessibility?
* [ ] Does the platform support live captioning?
* [ ] If yes, have we shared instructions on enabling captioning for virtual attendees?
* [ ] Are interpretation channels set up for multiple languages (if applicable)
* [ ] Is the session being recorded?
* [ ] Will recordings be shared afterward?
  * [ ] If yes, prepare resources (e.g., slides, recording, etc)
* [ ] Are materials shared in advance?
* [ ] Are chat and Q\&A functions accessible and monitored by a designated point of contact?
* [ ] Is there an alternate medium available in case of a power or internet outage? (e.g., mobile hotspot)

#### Participant Logistics & Visa

* [ ] Have we confirmed which participants require childcare/caregiving support?
* [ ] Have we clarified what type of support would be most helpful?
* [ ] Have we verified the mode of transportation for all attendees (e.g., flights, ground transport, etc)
* [ ] Have we confirmed participants requiring travel support and made arrangements accordingly?
* [ ] Have we confirmed the number of participants requiring a visa?
* [ ] If yes, have we collected visa details? (e.g., full name as per passport, DOB, passport no, country, etc.)
* [ ] Have we provided visa support letters?
* [ ] Have requested accommodations been coordinated and confirmed directly with participants?
* [ ] Have any special requests been noted and coordinated with the place of accommodation? (e.g., room sharing, accessibility, etc).

#### Participant Safety & Consent

* [ ] Have we obtained consent for photos, videos, and other media during the event from all attendees?
* [ ] Have we taken note of any restrictions from attendees (e.g., no photos, no videos, internal use only)?
* [ ] Have non-consent cases been clearly identified (e.g., list, badges/name tags, seating plan, etc)
* [ ] Have photographers, videographers, media, and relevant coordinators been informed of attendees who did not grant consent?
* [ ] Have clear instructions been given on how to avoid capturing attendees without consent to the media/photography team (e.g., framing, seating arrangements, post-event editing)?
* [ ] Are consent forms stored securely?
* [ ] Access restricted to authorised staff?
* [ ] Are participants informed how images/videos will be used and for how long (e.g., reports, social media, internal documentation)?
* [ ] Is there a designated point of contact responsible for monitoring consent compliance during the event?

#### Cultural & Inclusion Considerations

* [ ] Are event dates mindful of major religious or cultural holidays?
* [ ] Are breaks scheduled for prayer or personal time if needed?
* [ ] Is the dress code culturally appropriate?
* [ ] Are panelists/speakers diverse and representative?
* [ ] Are facilitators briefed on inclusive language, avoiding stereotypes, and cultural sensitivity?

#### Final Pre-Event Check

* [ ] Team has been briefed on roles, responsibilities, and responding to accessibility issues
* [ ] Venue, seating, and audio/sound setup checked
* [ ] Catering and dietary requirements confirmed
* [ ] Participant logistics confirmed (e.g., transport, visas, childcare/childgiving)
* [ ] Consent and media compliance reconfirmed
* [ ] Contingency plans reviewed (e.g., power outages, connectivity, emergency procedures)
