# CSIDNet Regional Convenings Playbook

This kit is designed to support regional co-hosts in planning and delivering CSIDNet convenings without having to start from scratch. It provides shared templates, guidance, and processes that help maintain a consistent level of quality across events while still allowing each region to shape the convening in ways that are locally meaningful.
